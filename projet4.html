🚀 Projet 4 : Script d'Automatisation de Création d'Utilisateurs Active Directory

Développement d'un outil en PowerShell/Bash pour optimiser les tâches administratives récurrentes.

Dans le cadre de l'optimisation des procédures d'intégration des nouveaux employés, j'ai conçu un script d'automatisation (en PowerShell pour un environnement Windows Server/AD) permettant la création massive et normalisée de comptes utilisateurs. L'objectif était de réduire le temps de déploiement et d'éliminer les erreurs manuelles.

Ce script lit un fichier source (CSV), crée l'utilisateur dans l'Active Directory (nommage standard, mot de passe initial, ajout au groupe approprié), lui assigne un répertoire personnel et configure les permissions de base. Ce projet démontre ma maîtrise du Scripting (SISR), de l'administration AD et ma capacité à développer des solutions d'automatisation pour améliorer l'efficacité opérationnelle d'un service informatique.
